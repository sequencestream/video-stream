# 7 步向导操作说明

1. 打开 `http://localhost:8080/wizard/1`
2. 输入主题与类目，点击「开始向导」
3. 在 `/wizard/2` 选择选题卡片
4. 在 `/wizard/3` 三选一 Hook（应在 30 秒内）
5. `/wizard/4`–`5` 依次执行脚本定稿与素材规划
6. `/wizard/6` 720p 预览（可点「改一句重编译」）
7. `/wizard/7` 1080p 出片，输出路径显示在会话状态栏

构建内嵌 UI：`make webui-build && make build`

截图：运行上述流程后可在浏览器逐步截取；CI 不强制二进制截图入库。
